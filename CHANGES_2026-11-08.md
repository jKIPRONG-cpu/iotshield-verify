# Changes — 8 November 2026

## Added

- **`tools/verify_scale.mjs`** (`npm run verify:scale`). Runs the TypeScript
  model checker on 3, 4 and 5 devices, adding SN-1 (sensor, building,
  hardening 1, internal) and then MON-1 (monitor, clinical, hardening 0,
  internal). It reports verdicts only for explorations that complete below the
  state cap, and logs exploration time and memory.
- **`backend/requirements-dev.txt`**. The backend test suite needs an HTTP client
  for Starlette's TestClient, which `requirements.txt` did not list, so
  `npm run verify:backend` could not start. Install with
  `pip install -r backend/requirements-dev.txt`.
- **`verification-logs/2026-11-08/`**: the 4-device run with the Python
  re-implementation, the scalability runs with the TypeScript checker, and the
  first complete backend run (88/88).

## Corrected

- **Outdated VP-05 explanation in the application.** The scripted simulation
  (`frontend/src/lib/simulation.ts`, `backend/app/simulation.py`) and the
  Petri-net page (`frontend/src/pages/PetriNet.tsx`) still said the containment
  failure came from "Detect Malware and Analyse Behaviour being concurrently
  enabled". They now give the verified cause: the deferral arc returns the
  device to Suspicious Behaviour without a new observation, so the detector can
  stay disabled. The Petri-net page also states that the animation is not the
  verified artefact.
- **Removed invented figures from the source.** `mock.ts` and `data_gen.py` still
  contained six hand-written property entries ("3.1% of sampled runs",
  "4.2 seconds of exposure", made-up counterexamples). They were no longer
  displayed, only counted to keep the random draws aligned. They are replaced
  by a constant `LEGACY_VERIFICATION_DRAWS = 6`, so the generated data is
  unchanged (`npm run verify:parity` still passes).
- **Six properties → eight** wherever the interface or documentation still said
  six: landing page, research overview, AI assistant, simulation, Verification
  page header, `README.md`, `backend/README.md`.
